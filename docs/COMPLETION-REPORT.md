## Run locally

Extract FINAL.zip. Open the inner **ba-portfolio** folder in VS Code — the one containing package.json. Install Node 24 LTS if needed, open Terminal → New Terminal and run:

```sh
npm ci
npm run dev
```

Open the Local URL printed in the terminal. Ctrl+C stops the server. Double-click **START-HERE.html** for all beginner steps; do not double-click index.html to run the application.
